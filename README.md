## ✨ Features

| | Feature | Description |
|---|---|---|
| 🌐 | **Web-Based Interface** | Clean and simple interface for translating text directly from your browser. |
| ⚡ | **Local Processing** | Runs through a local Node.js application without requiring a hosted translation service. |
| 🔌 | **QVAC Integration** | Uses the QVAC SDK as the interface to the translation runtime. |
| 🧠 | **Bergamot Translation** | Uses the Bergamot translation model for machine translation. |
| 🔒 | **Privacy-Focused** | Translation processing is designed to remain within the local application environment. |
| 🚀 | **Lightweight** | Simple Node.js setup with minimal requirements. |
